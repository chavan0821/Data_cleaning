# Data_cleaning
# Swyynex Task 1 - Data Cleaning and Preparation

## Project Description

This project focuses on cleaning and preparing a raw customer dataset for further data analysis.

I used **Python, Pandas, and Jupyter Notebook** to identify and handle common data quality issues such as missing values, duplicate records, incorrect data types, and inconsistent values.

## Tasks Performed

- Loaded and explored the raw dataset
- Identified missing values
- Detected and removed duplicate records
- Checked and corrected data types
- Identified inconsistent categorical values
- Removed unnecessary spaces
- Standardized categorical values
- Handled missing numeric values using median
- Handled missing categorical values using mode
- Performed final data validation
- Saved the cleaned dataset as a CSV file

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Project Files

- `raw_dataset.csv` – Original raw dataset
- `cleaned_customer_dataset.csv` – Cleaned dataset
- `data_cleaning.ipynb` – Complete Python data cleaning process
- `README.md` – Project description and cleaning steps

## Result

After cleaning, the dataset was prepared for further analysis with missing values and duplicate records properly handled.

## Conclusion

This project helped me gain practical experience in **data cleaning, data preprocessing, and data quality checking using Python and Pandas**.
